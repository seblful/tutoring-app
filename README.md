# Tutoring App

An Android tutoring application built with **Kotlin** and **Jetpack Compose**.

## Tech Stack

- Kotlin
- Jetpack Compose
- Gradle

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/seblful/tutoring-app.git
   ```
2. Open the project in Android Studio.
3. Let Gradle sync, then run the app on an emulator or device.

## Build

```bash
./gradlew assembleDebug
```
